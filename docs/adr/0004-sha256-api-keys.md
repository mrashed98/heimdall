# API keys hashed with SHA-256, not argon2

API keys are 32 random bytes generated by Heimdall, not human passwords, so they cannot be brute-forced from a hash and a slow password hash adds no security. On a 1-CPU pod, argon2 on every authenticated request would cost real CPU. Keys are stored as SHA-256 and looked up by hash. If human-chosen secrets are ever accepted, this must change.
