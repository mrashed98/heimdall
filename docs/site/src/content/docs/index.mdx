## One small watcher, five jobs

Heimdall is a lightweight replacement for OWASP Dependency-Track, written in
Rust. It is one binary, one Deployment and an external Postgres, and it fits in
about 256 MB of memory (hard limit 1 GB and 1 CPU).

<CardGrid stagger>
  <Card title="Sight" icon="magnifier">
    Knows what you run. It reads your cluster (pods, nodes, Helm chart labels,
    ArgoCD Applications), image SBOMs, SBOMs uploaded from CI, and components
    you declare by hand.
  </Card>
  <Card title="Watchers" icon="rocket">
    Hear the grass grow. They poll GitHub, endoflife.date, OCI registries, Helm
    repos, Terraform registries, the Go proxy and npm for new releases and
    end-of-support dates.
  </Card>
  <Card title="Gjallarhorn" icon="bell">
    Sounds the alarm in Microsoft Teams. One card per advisory or release, sent
    once, plus a weekly digest of everything that did not need an immediate
    alert.
  </Card>
  <Card title="Hofund" icon="approve-check">
    The CI gate. `heimdall gate` fails a build when it finds vulnerabilities,
    using the same data as the server, with exit codes your pipeline can
    trust.
  </Card>
  <Card title="Oaths" icon="pencil">
    Accept a risk on purpose. Snooze or ignore one advisory for one component
    in one service, with a reason, an owner and a date that brings it back.
  </Card>
  <Card title="Made to stay small" icon="seti:rust">
    Alerts when it matters, not noise. Matches against OSV and NVD without
    mirroring either, and keeps all state in the Postgres you already run.
  </Card>
</CardGrid>
