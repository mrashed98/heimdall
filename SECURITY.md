# Security policy

Heimdall is a security tool, so we take reports about Heimdall itself seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through
[GitHub security advisories](https://github.com/mrashed98/heimdall/security/advisories/new).

Include what you found, how to reproduce it, and the version affected. You will get an
acknowledgement within 7 days. Once a fix is released, the advisory is published with credit
to you unless you prefer otherwise.

## Supported versions

Only the latest release receives security fixes while Heimdall is pre-1.0.
